## 配置与边界

- 查询跨度受 MaxQueryDays 约束；链路侧栏固定打开时的搜索时间窗。
- 链路最多展示 10000 个 span、200 条关联日志，超限提示截断；缺失父节点提示不完整。
- 筛选值计数来自时间窗抽样，不代表筛选后的精确分布。

## 常见故障与处置

| 现象 | 处置 |
|---|---|
| 查询拒绝 | 检查字段、操作符及时间跨度；属性使用 attributes./resource. 路径 |
| 链路缺少节点 | 扩大搜索时间范围后重新打开；检查采集及保留策略，不将缺父节点视为根 |
| 加载失败 | 点击重试；检查 analytics 查询错误与冷层可达性 |
| 历史短 span 耗时为零 | 旧数据采集时已损失精度，升级只能修复新采集数据 |
| 关联日志未显示 | 检查 trace_id/span_id 关联、时间范围与截断提示 |

## 服务地图

- 入口：图表探索之后的「服务地图」，`/service-map`；SQL 为 WHERE 表达式，Lucene 为链路条件。服务与条件命中 Trace 后保留窗口内上下游。
- Sampling 按 Trace 稳定采样，默认 100%；显示的是样本统计。少量链路可能采样为空，应提高比例而非断言服务不存在。
- 缺父提示可通过扩大时间范围、检查采集完整性排查；图只关联窗口内已知父子片段，不补猜测边。
- 超限保留 100 服务/300 依赖，服务下拉前 200 项，样例前 20 条；缩小时间或条件后重查。采样不等于扫描成本硬限额。
- 验收：服务/SQL/Lucene/采样/时间运行 → 点击时间桶缩窗 → 节点聚焦上下游 → 依赖样例 → Trace 瀑布查看真实顺序；检查错误重试、空态、缺父与裁剪提示、URL 恢复和亮暗主题。
- 宽窄屏布局验收：宽屏服务/语法/搜索与执行操作同排，搜索弹性填充；窄屏按查询与执行分组换行，服务、语法和指标下拉不得各占整行，长服务名省略不撑宽。
- 高度验收：增高窗口后画布占满剩余空间；缩小窗口保留至少 360px 画布并允许页面滚动。详情内容独立滚动，不拉长整张图；时间轴维持 100px。
- 当前自动化结果和浏览器登录限制见 [tdd](tdd.md)，未完成的真实交互不得当作已验收。

## 验收

1. 打开搜索页，切到链路，检查专属 filters、根 span 和毫秒耗时范围。
2. 展开记录，在概览/列值中搜索完整属性；行点击打开宽侧栏。
3. 点击树节点/时间条及条尾标签核对同一 span 的名称、耗时与右侧详情；长中英文名称单行省略，短条、右边界和窄屏无溢出，缩放右裁剪用 → 提示。测试折叠、复位和日志/事件开关。
4. 检查服务地图与关联日志；点击日志/事件标记查看对应详情，核对未关联日志独立行与截断提示。
5. 打开上下文，切换 traces/logs、±时间窗、同服务/同主机/自定义属性；查看记录不改变锚点，点击「以选中记录查看上下文」才重新定位。核对每批 100 条续载、失败重试和结束标识。
5. 检查亮暗主题、窗口缺数据/截断、失败重试、遮罩与 Esc 关闭。
6. 自动验证命令与实际结果见 [tdd](tdd.md)。
