# logs — SOP

> 关联：[sdd](sdd.md) · [bdd](bdd.md) · [tdd](tdd.md)

- 端点：`GET /api/logs?page&pageSize&service&severity(逗号分隔)&search&start&end`；`GET /api/logs/services`。
- 默认查询最近 1 小时；长区间请显式传 start/end（上限 MaxQueryDays）。
- 关键字检索为包含匹配（LIKE），大区间慎用。
- 无数据排查：确认接入侧已落库（/metrics 的 processed 计数），再确认时间范围。
- 超长消息体验收：大段堆栈/超长单行默认收缩且不撑宽侧栏，展开后区域内滚动；收起恢复限高，复制保持全文。浏览器实际布局验收需登录态。
- 上下文验收：首批 100 条，滚动近底部追加下一批；续载失败点击重试，已有行保持；无更多数据时出现「已显示全部结果」。切换时间窗/匹配条件重新加载首批。
- 上下文可选同主机或嵌套属性；查看详情后关闭仍返回原列表，只有「以选中记录查看上下文」改变锚点。缺主机属性明确提示，不退化为任意查询。
- 历史 NULL ID 日志仍参与分页；浏览期间若发生补写/清理，OFFSET 位置可能移动，重新打开上下文刷新列表。
